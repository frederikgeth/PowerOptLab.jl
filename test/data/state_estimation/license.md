# Power-flow comparison fixtures

Small synthetic OpenDSS cases authored for BMOPFTools, each exercising one
modelling feature (winding configurations, split-phase, regulators, grounding
variants) in the BMOPF ↔ OpenDSS power-flow cross-check suite. Not derived
from utility data.

License: Creative Commons Attribution 4.0 International (CC BY 4.0), per the
repository's benchmark-data policy (see the root README).

Source: frederikgeth/BMOPFTools.jl, commit 72e6cec22a66cf376c37ec4d64aef350b9f1100d. Component decks copied for estimator-specific tests, with modifications listed below; inline network builders copied from powerflow_comparison_tests.jl.

PowerOptLab modifications: center_tap.dss is a new synthetic split-phase case.
The open-delta fixture adds 1 kOhm phase-earth shunts for a physical common-mode
reference. The finite IEEE13 variant is generated by the companion Julia fixture
and uses the original repository IEEE13 transcription with explicitly changed
leakage, losses and load models; it is not the original IEEE operating case.
