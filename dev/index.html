PowerOptLab.jl

PowerOptLab provides models and numerical methods for studying four-wire distribution networks with uncertain states and parameters.

Start here

The getting-started example builds a small feeder, schedules a battery and checks the solution. It uses synthetic data and Ipopt. The example is run automatically when the documentation is built.

For an existing checkout, install the pinned dependencies from its root:

julia --project=. scripts/instantiate_pinned.jl

Then choose a study topic below. For a complete worked experiment, follow the battery-model comparison or four-wire state-estimation study. Both include figures, expected results and executable checks.

Research context

The research programme addresses three questions:

  1. Which network states and parameter values are consistent with measurements and network records?
  2. Which additional measurements or changes in operating point would distinguish the plausible models while respecting voltage and equipment limits?
  3. Which operating decisions remain feasible under those models?

The package builds on the BMOPFTools reference current–voltage OPF formulation. It uses the same network equations, with an explicit neutral conductor and per-unit scaling, and adds models through the public model-building functions.

The current package provides separate estimation, optimisation and checking methods. Joint network-model identification and automatic experiment design remain research objectives. The nonlinear DOE solvers also lack a general feasibility certificate for continuous uncertainty and utilisation sets. Concepts explains the modelling assumptions and conventions; the research programme sets out the longer-term questions.

Extending the package

See Contributing for adding a model or solution method. Models with sufficiently established interfaces and validation may be proposed for inclusion in BMOPFTools.
