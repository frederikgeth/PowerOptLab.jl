Device models and scheduling

The device model determines which electrical limits and stored states appear in the optimisation. The guides below cover generators, stationary batteries and EV charging. The multi-period OPF guide shows how storage and EV energy balances link successive operating points.

FamilyStudy questionStart here
GeneratorsStudy the effects of source impedance, voltage regulation, winding connection and grounding.Generator overview
Battery storageCompare power-energy scheduling with a model of cell voltage and current limits.Battery storage overview
Electric vehiclesCalculate charging schedules subject to outlet ratings, availability and departure energy.Electric vehicle overview

The scheduling API describes the multi-period solver. The generator and IVQ models have separate solvers, listed in their API references.

The inverter chapter covers converter circuits, losses, ratings and local control laws for studies in which these determine the feasible operating region.

Model assembly

Storage and EV devices contribute currents to the KCL equations at each operating point and energy-balance constraints between intervals. They implement AbstractDevice using validate_device, stamp_device!, link_device! and extract_device. solve_multiperiod_opf assembles and solves the complete schedule.

See Concepts for units, sign conventions and interpretation of solver status, and the shared API for the common programming interfaces. The neutral reduction reference describes the assumptions and changes involved in eliminating a grounded neutral.
