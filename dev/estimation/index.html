State estimation

Kind: Problem specification · Direction: inverse · Maturity: prototype

For calibration or line-construction questions, begin with the estimation overview. The compiled API offers dense, sparse and classic Ipopt solvers over one model; their functions and arguments are listed in the state estimation API.

State estimation determines bus voltages from measurements and an assumed network model. PowerOptLab provides a JuMP/Ipopt WLS estimator and a constrained nonlinear least-squares estimator. Their treatment of exact device equations, measurements and numerical solution differs.

Legacy WLSConstrained NLLS
Entry pointsolve_state_estimationcompile_state_estimator + a solver
Statement$\min \sum_i (z_i - h_i(x))^2/\sigma_i^2$$\min \tfrac12\lVert r(x)\rVert^2$ s.t. $c(x)=0$
EngineJuMP + IpoptGauss–Newton / Hachtel / shared Ipopt solvers

Both APIs report J=sum(abs2,r) through solve_diagnostics; the internal factor one half in the compiled objective does not change that public statistic.

Choosing a formulation compares the two estimators on the same network and measurements.

What both of them assume

Both methods rely on the following assumptions. Errors in those assumptions can bias the estimate even when the numerical solver converges:

  • Measurement weights are diagonal. Both estimators scale residuals by $1/\sigma$ and do not support correlated measurement errors. Independent, zero-mean Gaussian errors give the weighted least-squares objective its maximum-likelihood interpretation. Least-squares fitting can also be used under other error distributions, but the likelihood, covariance and residual tests then need separate justification. A systematic meter offset requires analysis of bias as well as random noise. See likelihood, loss, and priors.
  • Topology and line parameters are exact. Neither estimator hypothesises a different switch status or a different impedance. A topology error can produce large residuals or be partly absorbed into the estimated voltages. See parameter estimation and inverse Carson for the complementary problems.
  • The estimate is a local stationary point. Both problems are nonconvex. Convergence is not uniqueness, and neither estimator does multistart. The current-magnitude tutorial shows two different states that both fit the same data exactly, each reported as converged.
  • Observability requires rank; precision also depends on conditioning. Measurement placement determines which state directions are identified. Small singular values indicate directions that are weakly supported by the data. See observability.
  • Standard deviations determine the relative measurement weights. Assign uncertainties according to the evidence for each reading or forecast. Giving a load forecast the precision of a calibrated meter can overstate the information it contributes.
