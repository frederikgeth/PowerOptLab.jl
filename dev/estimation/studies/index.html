State and parameter estimation

The appropriate estimation method depends on which quantities are unknown and which measurements are available. PowerOptLab provides state estimation, calibration of selected line lengths and taps, and overhead-line reconstruction.

Estimation problemRequired data and assumptionsGuide
Estimate bus voltages from noisy measurements.Measurements and their uncertainties; known topology and parametersState estimation
Estimate line lengths or transformer taps using several operating points.Measurements at each operating point; fixed topology, conductor connections and per-length R/XParameter calibration
Identify overhead-line configurations consistent with sequence impedances.Sequence impedances and candidate conductor geometries and materialsInverse Carson reconstruction

Selecting a method

For state estimation, begin with the formulation comparison, then the modelling tutorial. Use observability and likelihood, loss and priors to interpret the result. The state estimation API lists measurement types, solvers and returned diagnostics.

The calibration guide contains a complete example in which line lengths and taps are common to several snapshots. The calibration API describes the input parameters and estimated quantities.

The line reconstruction tutorial tests candidate conductor arrangements and constructs the corresponding four-wire line models. The line reconstruction API describes the inputs, fitted models and parameter profiles.

Interpreting the estimates

A state estimate is conditional on the assumed network parameters. A calibration result is a local fit to the specified measurements. Line reconstruction can return several configurations that fit the same sequence impedances. When using these results in an operating-envelope study, carry the remaining uncertainty into the network scenarios. Joint estimation across these problems is a research objective described in the research programme.
